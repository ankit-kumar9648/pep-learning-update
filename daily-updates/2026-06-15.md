# C++ Pattern Programs - PEP Class

This repository contains basic C++ pattern programs practiced during PEP classes.

---

## 1. Square Star Pattern

### Code

```cpp
#include <iostream>
using namespace std;

int main()
{
    for(int i = 1; i <= 5; i++)
    {
        for(int j = 1; j <= 5; j++)
        {
            cout << "*";
        }
        cout << "\n";
    }

    return 0;
}
```

### Output

```
*****
*****
*****
*****
*****
```

## 2. Square Pattern Using Row Number

### Code

```cpp
#include <iostream>
using namespace std;

int main()
{
    for(int i = 1; i <= 5; i++)
    {
        for(int j = 1; j <= 5; j++)
        {
            cout << i;
        }
        cout << "\n";
    }

    return 0;
}
```

### Output

```
11111
22222
33333
44444
55555
```

## 4. Reverse Row Number Pattern

### Code

```cpp
#include <iostream>
using namespace std;

int main()
{
    for(int i = 5; i >= 1; i--)
    {
        for(int j = 1; j <= 5; j++)
        {
            cout << i;
        }
        cout << "\n";
    }

    return 0;
}
```

### Output

```
55555
44444
33333
22222
11111
```
