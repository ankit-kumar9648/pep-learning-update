## Additional Learning: Bit Manipulation

### LeetCode 191 - Number of 1 Bits (Hamming Weight)

#### Concept Learned

* Introduction to Bit Manipulation
* Brian Kernighan's Algorithm
* Understanding how binary operations work efficiently

#### Key Insight

```cpp
n & (n - 1)
```

This operation removes the **rightmost set bit (1)** from a number.

#### Example

```text
n = 12  →  1100
n - 1   →  1011

1100
1011
----
1000
```

The rightmost set bit gets removed.
