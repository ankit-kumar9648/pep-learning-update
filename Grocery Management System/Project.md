# 🛒 Grocery Management System

## 📌 Project Overview

The Grocery Management System is a console-based application developed in **C++** using **Object-Oriented Programming (OOP)** and **File Handling** concepts. The project is designed to automate grocery store operations such as maintaining product records, customer information, purchase details, and report generation.

The application stores all records in files, ensuring data persistence even after the program is closed. It provides an easy-to-use menu-driven interface for managing grocery-related information efficiently.

---

# 🎯 Objective

The main objective of this project is to develop a simple yet effective grocery management system that minimizes manual work and demonstrates the practical implementation of file handling and object-oriented programming concepts in C++.
